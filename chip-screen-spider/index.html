MACHINE SHOP PRODUCT

Chip Screen Spider

Auger-driven screen sweeper for select Haas mills.

Chips can collect over the screen holes beside the auger, blocking coolant from draining back into the reservoir. The turning auger drives the Chip Screen Spider, sweeping those chips off the screen and into the auger instead of leaving them to be cleared by hand.

CONFIRM FITMENT

Measure before ordering

Fits Haas VF-Series mills that match all three measurements below. Verify all three measurements before ordering.

  • Screen holes3/16-inch diameter
  • Mounting-hole row2-3/8 inches from the auger, ±0.125 inch
  • Auger screw pitch5 inches, ±0.125 inch

Fitment is determined by these measurements—not by machine model alone.

WHAT'S INCLUDED

Two spiders and installation hardware

  • Two translucent-orange PETG Chip Screen Spiders
  • One stainless-steel installation hardware set
  • Printed installation instructions
  • QR code linking to the installation video

INSTALLATION

Uses one existing screen hole

Tap the specified existing 3/16-inch hole 1/4-20. The included threaded rod serves as the axle so the spider can rotate as the auger pushes its arms.

Correct mounting location is critical. Installing it in a different hole position may break the spider. Remove the spider before servicing or removing the auger.
