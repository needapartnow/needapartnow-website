HAAS G13 CIRCULAR POCKET

7.875 diameter × .250 deep

This example uses a .500-inch center-cutting end mill. X0 Y0 is the pocket center and Z0 is the top of the part.

Before you run it

  • On a Haas Classic control, press SETTING/GRAPH, go to Setting 40, and set it to DIAMETER.
  • Enter .500 on the tool-offset page for the tool that matches what you have in the spindle. Write down the previous value and put it back when you are finished.
  • K is the finished pocket radius. Change it to one-half of your required finished diameter.
  • To use a different-diameter cutter, change the tool number and Q, then enter the new cutter diameter on the matching tool-offset page.
  • Start with I.300 as shown. The I value only needs to be smaller than the largest circle diameter you are going to cut.
  • Change the spindle speed, feedrate, pocket depth, and safe positions for your machine, cutter, material, and setup.

Verify every value for your machine and setup. Run Graphics, then single-block it above the part before cutting.

What this program needs

  • A Haas control with the macro option and G47 text engraving.
  • Setting 29 must be OFF.
  • Set G54 X0 Y0 at the center of the engraving circle.
  • Set G54 Z0 at the top of the finished engraving surface.

What you edit

  • Edit only the clearly marked OPERATOR EDIT SECTION. Leave everything below DO NOT EDIT BELOW THIS LINE alone.
  • #100 through #110 control the tool, RPM, depth, feed, circle size, character size and spacing, center location, and Z clearances.
  • #111 is the number of fixed characters you are using, from 0 through 30.
  • #112 is the selected angle: 0 is +X, 90 is +Y, 180 is -X, and 270 is -Y.
  • #113=0 starts the first character at that angle. #113=1 centers the complete engraving at that angle.
  • #114=0 repeats the same fixed text every cycle. #114=1 adds an automatic serial number and advances it after a completed engraving cycle.
  • #600 is character slot 1, #601 is slot 2, and the pattern continues through #629. Use the character key printed in the program and keep each slot comment updated so the text is readable at the machine.

Automatic serial numbers

When #114=1, macro variable #580 holds the next serial number to engrave. If it is empty, the program starts at 1. To restart or jump to another number, open the Haas macro-variables page and change variable 580. This version accepts serial numbers 1 through 99 without leading zeros.

Prove-out procedure

  1. Check every operator-edit value and confirm the correct tool is loaded.
  2. Run Graphics first, then single-block above scrap material.
  3. Leave Block Delete OFF during prove-out. The optional-stop block pauses with the tool at Z1.000 so you can confirm it is one inch above the part.
  4. After Cycle Start, the program explicitly restarts the spindle and turns coolant on before engraving.
  5. After the program is proven for your setup, turn Block Delete ON to skip the sanity-check stop.

This code ran successfully on the machine shown, but you are responsible for verifying every tool, offset, clearance, setting, and value on your own machine. Test on scrap first.
